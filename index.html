Запуск каталога GameVoice

Привет. Это первый полноценный релиз сайта. Я сделал GameVoice, потому что устал собирать ссылки на переводы и фанатские озвучки по разным форумам, пабликам и файлообменникам. Теперь всё находится в едином открытом месте.

Каталог пополняется регулярно. Если вы знаете русификатор, которого здесь пока нет, или нашли нерабочую ссылку — нажмите на кнопку добавления. Это открывает заявку на GitHub и очень помогает проекту развиваться.

  • Поиск и фильтры по типу локализации (текст, озвучка, всё вместе)
  • Интерактивный hero-блок с трейлерами и адаптивными постерами
  • Сохранение избранных игр локально в браузере
  • Удобная форма предложения новых русификаторов через GitHub Issues

Вопросы и ответы

Как установить русификатор?

Инструкция обычно находится на странице автора локализации. Мы собираем и структурируем ссылки на первоисточники.

Файлы хранятся на вашем сервере?

Нет, GameVoice работает исключительно как каталог со ссылками на официальные ресурсы команд, группы VK, Boosty и открытые репозитории.

Как предложить локализацию?

Воспользуйтесь кнопкой «+» в шапке сайта или внизу экрана. После заполнения формы будет автоматически создан запрос на GitHub.

GameVoice

Добро пожаловать. GameVoice — это открытый каталог локализаций, созданный для удобного поиска озвучек и переводов для игр.

Кто делает проект

Меня зовут Stintik-123. Вы также можете знать меня по проекту vpn-configs-russia. GameVoice — ещё одна некоммерческая инициатива, сделанная для людей.

Зачем нужен этот сайт

Информация о фанатских переводах и озвучках рассеяна по всему интернету: Nexus, VK, Telegram, Boosty, Playground и сторонние сайты. Искать актуальную версию каждый раз некой удручающий процесс. GameVoice объединяет всё в одном месте с понятной структурой и ссылками на авторов.

Что есть в каталоге

  • Интерактивный витринный блок: Трейлеры с YouTube на ПК и адаптированные постеры для мобильных устройств.
  • Фильтрация и поиск: Быстрый отбор по типу локализации, статусу готовности и жанру.
  • Карточки проектов: Сведения о студии, полноте перевода и прямые ссылки на авторов.
  • Приватность: Избранное сохраняется исключительно в вашем браузере (localStorage).
  • Открытость: Любой желающий может дополнить базу через GitHub Issues.

Чего здесь нет

  • Локального хостинга файлов — каталог предоставляет только ссылки на оригинальные источники.
  • Игр с официальной русской локализацией по умолчанию.
  • Рекламы и сомнительных промежуточных редиректов.

Как поддержать развитие

Единолично поддерживать актуальность каталога непросто. Если вы знаете перевод или озвучку, которых здесь нет, нажмите + Предложить игру. Каждая предложенная ссылка делает базу лучше.
